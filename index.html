Getting Started

1. Sign up to the Grow Master app using the "Create An Account" link.

2. Create a new grow cycle using the "+" icon in the top right hand for the IOS application.

3. Create an event for a grow cycle by clicking on the grow cycle on the main view, clicking the hamburger stack top right, and then clicking on the "Add Event" link.

Troubleshooting

For synchronization issues or if you're not seeing an event or for general errors, sign out of the application and sign back in.

For navigation issues, Ensure you're using the links in the toolbar to navigate back to where you came from. Check the views for the Tabs. Keep in mind that each tab has its own unique navigation view stack/history.
